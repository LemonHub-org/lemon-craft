## 背景资源

共有 42 张 JPG 背景。主菜单代码当前从其中 24 张构成的候选池中随机选择，候选池定义在 `voxygen/src/menu/main/ui/mod.rs` 的 `BG_IMGS` 中。

阶段 1 前应完成：

- 标记过暗、过紫、过冷和主体位置不适合文字叠加的背景。
- 为登录、角色选择、连接页分别定义可接受的背景池。
- 保留足够的场景多样性，但控制整体色温和对比度。

## 字体

UI 代码使用 3 个逻辑字体：

- `universal`：通用正文和聊天文本
- `cyri`：主要 UI 标题、按钮和 HUD 文本
- `alkhemi`：特殊字体/语言场景

字体由本地化清单提供，切换语言时同时加载 Conrod 和 Iced 字体实例。阶段 0 暂不替换字体，阶段 6 再针对长文本、数字和多语言做适配测试。
